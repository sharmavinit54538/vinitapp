# OFC360 HRMS — Asset Management Module REST API Contract (Procurement to Retirement)

**Base Path**: `${NEXT_PUBLIC_API_BASE_URL}/api/v1/assets`
**Authentication**: `Authorization: Bearer <access_token>` (sourced from `authClient.getAccessToken()` in `lib/auth-api.ts`)
**Standard Error Envelope**:
```json
{
  "error": {
    "code": "FORBIDDEN | VALIDATION_ERROR | NOT_FOUND | CONFLICT | INTERNAL_ERROR",
    "message": "Human-readable error description",
    "details": {}
  }
}
```
**Standard Error Codes**: `400` Validation Error, `401` Unauthorized, `403` Permission Denied (RBAC), `404` Resource Not Found, `409` Conflict / State Transition Invalid, `422` Business Rule Violation, `500/502/503/504` Server Error (idempotent `GET` requests automatically retry).

---

## Role-Based Access Control (RBAC) Roles
- `super_admin` (Super Admin)
- `asset_admin` (Asset Admin)
- `it_admin` (IT Admin)
- `facilities_admin` (Facilities / Admin)
- `finance` (Finance)
- `procurement` (Procurement)
- `hr_admin` (HR Admin)
- `reporting_manager` (Reporting Manager)
- `auditor` (Auditor)
- `employee` (Employee)

## 1. Asset Dashboard (`dashboard`)
- **GET** `/api/v1/assets/dashboard/summary`
  - **Query**: `from`, `to`, `categoryId`, `department`, `location`, `legalEntity`, `vendorId`
  - **Response**: `AssetDashboardResponse` (10 KPI cards, 6 chart series: category distribution, department allocation, asset age, maintenance cost trend, utilization, depreciation trend, plus SLA breaches, expiring warranties/licenses, and live automation alerts)
  - **Permissions**: `super_admin`, `asset_admin`, `it_admin`, `facilities_admin`, `finance`, `procurement`, `hr_admin`, `reporting_manager`, `auditor`
  - **Status**: Required from backend

## 2. Asset Register / Inventory (`register`)
- **GET** `/api/v1/assets/register`
  - **Query**: `page`, `pageSize`, `search`, `category`, `status`, `location`, `condition`, `sortBy`
  - **Response**: `PaginatedAssetResponse<AssetRegisterRecord>`
  - **Status**: Required from backend
- **GET** `/api/v1/assets/register/:id`
  - **Response**: `Asset360ProfileResponse` (details, allocation history, maintenance history, documents, financials, timeline, QR code payload, linked accessories)
  - **Status**: Required from backend
- **POST** `/api/v1/assets/register`
  - **Body**: `CreateAssetPayload` (tag auto-generated by backend, category, make, model, serialNumber, imei, purchaseDate, vendorId, purchaseCost, warrantyEndDate, location, condition, customFields)
  - **Response**: `AssetRegisterRecord`
  - **Status**: Required from backend
- **POST** `/api/v1/assets/register/bulk-import`
  - **Body**: `FormData` (`file`: CSV/XLSX)
  - **Response**: `{ validRowsCount: number; errorRowsCount: number; previewId: string }`
  - **Status**: Required from backend
- **POST** `/api/v1/assets/register/:id/reveal-sensitive`
  - **Response**: `{ assetId: string; unmaskedSerialOrImei: string; unmaskedCost: number }`
  - **Permissions**: `super_admin`, `asset_admin`, `it_admin`, `finance`, `auditor`
  - **Status**: Required from backend
- **GET** `/api/v1/assets/register/export`
  - **Query**: `format=csv|xlsx|pdf`, `category`, `status`
  - **Response**: Binary Blob stream
  - **Status**: Required from backend
